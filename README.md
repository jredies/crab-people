# Crab People 🦀

Crab People is a personal automation project built on top of OpenClaw, designed to integrate fitness and recovery data (e.g. WHOOP, Strava) into intelligent agents that provide actionable insights.

## Overview

This project connects wearable and activity data sources to AI agents in order to:

- Track daily activity (workouts, runs, etc.)
- Monitor recovery metrics (sleep, HRV, strain)
- Generate simple, actionable recommendations
- Enable automated decision-making (e.g. training intensity)

## Features (planned / in progress)

- WHOOP API integration (recovery, sleep, strain)
- Strava API integration (activities)
- Data normalization layer
- Agent-based decision system (OpenClaw)
- Daily readiness scoring

## Tech Stack

- OpenClaw (agent framework)
- JSON-based data pipelines
